Generate questions

A run walks the documentation pages this badge is about, one at a time, and writes several questions from each. Pages already written from are skipped, so running it again covers new material rather than repeating. This takes minutes — you can leave this page open and it will report when done.

Hold Ctrl (or Cmd) to pick several. The badges scope what the questions may test. Each finished question is then reviewed against the whole catalog and also filed under any other badge it genuinely tests.
25 pages at 3 questions each is up to 75 questions, and a few minutes per page. A run picks up where the last one stopped.
The same scale every question is tagged with. Advanced means deeper judgement — failure modes and why a recommendation holds — not obscurer trivia.
